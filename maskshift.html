02 · THE TOOLKIT

Maximal kit. Minimal context.

168 native tools

Files, shell, Git, LSP, browsers, containers, SSH, databases, PDFs and more — held out of context until a step calls for them.

Any model, really

Ollama, OpenAI, Anthropic, Gemini, OpenRouter, LM Studio, vLLM. No native tool API? A text protocol gives it the full surface anyway.

A code graph that remembers

Persistent file, symbol, import and call graph with reverse change-impact and likely-test discovery.

Crews in worktrees

Dependency-aware DAG plans run agents concurrently, each editor isolated in its own Git worktree.

A browser in your terminal

A live, clickable, typeable browser tab — the same connection the agent drives, rendered inline.

Bold, with a getaway plan

Permissive by default, so no approval pop-ups — backed by automatic checkpoints and an append-only audit log.
