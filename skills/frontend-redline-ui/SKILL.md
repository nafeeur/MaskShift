# MaskShift Racing UI

- Use near-black surfaces, hot red as the primary signal, controlled amber/cyan/white accents, clipped corners, speed lines, and instrument-panel geometry.
- Preserve legibility: body text remains calm while headings, state changes, and motion carry the racing character.
- Use dense but grouped information. Every panel needs a clear title, state, primary action, and empty/error behavior.
- Animate state transitions and telemetry, not continuous decorative noise. Respect reduced-motion preferences.
- Keep keyboard navigation, visible focus, contrast, responsive breakpoints, and touch targets functional.
- Verify at desktop, compact laptop, and narrow viewport sizes; eliminate clipping and horizontal overflow.
