# Changelog

## Unreleased

- **Removed the web UI and the HTTP daemon. MaskShift is now a terminal application: a full-screen TUI plus a complete CLI, and nothing else.** Deleted `public/`, `src/api/router.mjs` and `src/server.mjs`; dropped the `host`, `port` and `autoOpen` settings and the `serve` command. MaskShift no longer opens a listening socket of any kind. The systemd unit now runs `maskshift daemon` (the automation scheduler, no interface), and the container image runs the TUI with a TTY attached instead of exposing a port.
- Added `src/tui/`, a zero-dependency terminal interface written against Node built-ins: a truecolor/256/16-colour theme engine that degrades for `NO_COLOR` and `MASKSHIFT_ASCII`, ANSI-aware text measurement and wrapping (wide glyphs included), an alternate-screen frame buffer that diffs against the previous frame and rewrites only changed rows, a raw-mode key decoder covering control keys, CSI sequences, modifiers and bracketed paste, and a widget layer of editors, lists, viewports, spinners and toasts.
- Gave the interface its own design language, the **stencil frame**: every surface is a notched panel with an inset title tab and a bottom-rail stamp, and the focused panel is promoted from a hairline to a heavy crimson rule. Crimson carries identity and focus, gold carries keys and the operator, and each capability class keeps a fixed accent (cyanide for tools, violet for skills, azure for MCP) so the same colour always means the same category. The Phantom Protocol naming carries over from the previous UI — Target, Persona, Heist, Arsenal, Network, Mod Shop, Retreat — without touching the underlying `permissionMode` values.
- Reached feature parity with the removed cockpit across six views: **01 HEIST** (transcript with markdown, syntax-tinted code fences, coloured diffs, collapsible tool output and live in-flight tool calls, plus a soft-wrapping composer), **02 FILES** (foldable workspace tree and highlighted preview, with `a` to attach a file to the composer), **03 ARSENAL** (fuzzy search over every tool and skill, parameter-schema dossiers, and direct tool execution), **04 NETWORK** (MCP connect/disconnect, manual add, registry search and install), **05 MOD SHOP** (automations, plugins, agent bridges, browsers and processes) and **06 TERMINAL** (the host shell). A toggleable right rail carries the plan of attack, live loadout telemetry with token flow, the raw event bus and a Git pulse.
- Added a `ctrl+k` fuzzy command palette over every action, pickers for heists, models, workspaces and checkpoints, forms for settings, MCP servers, automations, plugins, browsers and tool arguments, plus slash commands (`/model`, `/tools`, `/mcp`, `/doctor`, …) and an `f1` key reference. The layout is responsive: below 108 columns the rail hides itself and the header sheds telemetry chips, so everything still works at 80×24.
- Added `src/cli/`, a styled non-interactive command surface covering every capability the interface exposes — `run`, `exec`, `doctor`, `daemon`, plus `workspace`, `session`, `tools`, `skills`, `mcp`, `plugins`, `automation`, `browser`, `config`, `models`, `lsp`, `bridges`, `ps`, `logs` and `events`. Every command supports `--json`, so MaskShift composes with shell pipelines and CI. `maskshift run` streams turns, tool calls and results live.
- Replaced the browser QA process with renderer assertions. `tests/tui.test.mjs` paints all six views, all four rail sections and all eleven overlays at 132×36 and again at 72×20, asserting every row is exactly the terminal width and the frame is exactly the terminal height; the key decoder, colour degradation, ANSI measurement, composer editing, list/viewport scrolling and frame diffing all have direct unit coverage. `tests/cli-agent.test.mjs` replaces the HTTP API test with the same two-turn agent loop driven through the CLI, and `npm run smoke` now paints the interface as part of its end-to-end run.
- Added `npm run capture` (`scripts/capture-tui.mjs`), which renders real frames to SVG by parsing back the ANSI the renderer emits — so `docs/screenshots/` is generated from the interface itself rather than from a browser. Replaced the PNG cockpit screenshots with these SVGs.
- Replaced the `frontend-phantom-ui` skill (which documented the removed web cockpit's CSS) with `terminal-phantom-ui`, documenting the terminal design language and the ANSI width discipline a TUI needs.
- Replaced `docs/API.md` with `docs/CLI.md` and `docs/TUI.md`, and updated the README, architecture, configuration, permissive-mode, security, contributing and release-verification docs for a terminal-only product. Added `ui.rail`, `ui.railVisible`, `ui.unicode`, `ui.colorDepth` and `ui.expandToolOutput` settings, plus the `MASKSHIFT_COLOR` and `MASKSHIFT_ASCII` environment overrides.
- Overhauled the cockpit into a fully maximalist Persona-styled Phantom UI across every view, not just the chat surface. Panels are torn graphic plates built from a shared `--plate`/`--shard`/`--blade` clip-path token set with a red bound-edge rule; halftone dot screens back the hero, brand, modal heads, gauges and card hovers; a scrolling hazard stripe welds the topbar to the stage; and panel headings, the run title and the hero headline all take a skew plus a hard red offset shadow. Motion was expanded throughout: staggered cascade entrances for the nav rail, session list, capability cards, registry results and starter prompts; wipe-in slabs on nav tabs, deck tabs and catalog tabs; skew/lift/glint feedback on every button; and a breathing target-lock reticle. View switching now plays **a different cut per destination** — shard rake (heist), vertical slats (files), ink splat (arsenal), all-out-attack ray burst (network) and a jagged tear (mod shop) — instead of one repeated diagonal wipe. The hero's `00` placeholder was replaced with the MaskShift mask mark inside the reticle.
- Fixed a long-standing bug that silently hid most of the arsenal, network and mod-shop catalogs: `.capability-card` set `overflow: hidden`, which makes a grid item a scroll container, and a scroll container's automatic minimum size is 0 — so every card row collapsed to its header height and clipped away the description text and the INSPECT/CONNECT buttons underneath. Cards now clip by `clip-path` alone (183px tall instead of 28px), and the card footer pins to the bottom edge so the status label no longer runs underneath its action button.
- Raised the cockpit's readability floor alongside the restyle. Every foreground token now clears 4.5:1 on the surface it sits on (`--dim` 3.4:1 → 5.6:1, `--red-glow` 4.9:1 → 5.4:1, terminal `stderr` 4.0:1 → 5.4:1, the brand sub-label 2.4:1 → 4.1:1), and no text renders below 10px — the previous design ran down to 6px, with 7–8px used for event feeds, capability tags, card metrics and plan-step detail. Added a `--red-deep` grade for red surfaces that carry small text, since white on `--red` is only 4.35:1. Type sizes, tracking, panel padding and card rhythm now come from a token scale rather than ad-hoc per-rule values.
- `web_search` now calls Brave, Tavily, or Exa when their API key is configured, falling back to the DuckDuckGo HTML scrape, with an explicit `provider` override.
- Added `pdf_read` for text extraction from PDFs via `pdftotext` (poppler-utils), with page-range and layout controls.
- Added `notebook_read` and `notebook_edit` for inspecting and editing Jupyter (`.ipynb`) notebook cells, clearing stale outputs on edit.
- Repository indexing now computes optional embedding vectors (via a local Ollama embedding model) alongside the existing SQLite FTS index, and `repo_search` blends both with reciprocal rank fusion. Embeddings are reused by content hash across reindexes, and the feature degrades silently to lexical-only search when no embedding model is reachable.
- Added Anthropic prompt caching: the stable system-prompt block (operating contract, repository context, capability catalog), the active tool schema list, and the conversation-so-far boundary are marked with `cache_control` breakpoints so a run's repeated turns reuse cached tokens instead of rebilling them. Disable per-provider with `promptCaching: false`.
- Fixed a bug where the Anthropic provider never read a tool call's `input` field, so tool-call arguments were silently dropped for every Anthropic-backed run.
- Added cost-estimation tooling: a new `usage_report` tool aggregates token usage and estimated spend per model across recent runs, and every completed run now carries a `costEstimate` in its metadata. Pricing comes only from the user-editable `pricing.models` config table (see `maskshift.config.example.json`); a model without a configured price is reported as token counts only, never a guessed cost. Local providers (Ollama) are always priced at zero.
- Made persistent memory ranking decay- and access-aware: `memory_search`/`memory_list` blend text relevance, importance, and an exponential recency decay (`memory.decayHalfLifeDays`, default 30) instead of ranking on raw importance or bm25 alone. `memory_save` now deduplicates by same-scope/same-title, merging tags and taking the max importance instead of accumulating duplicates. Added `memory_optimize` to find and (with `dryRun: false`) merge duplicate-title memories and prune stale, low-importance, never-accessed ones.
- Redesigned the cockpit UI to a strict black/orange/white palette (roughly 60/30/10) in place of the prior six-hue accent system. Category and status colors (skills/MCP/automation tags, connected/available/error states, plan-step and run-status indicators) are now expressed through a hazard-stripe motif (blocked/failed/danger) and a checkered-flag motif (completed) rather than hue, plus more motion throughout: entrance transitions, a drifting speed-streak background, CTA glint sweeps, and a scrolling hazard accent at the brand/topbar boundary. The logo mark was recolored to match. Refreshed all `docs/screenshots/*.png` to the new look.
- Replaced the racing-instrumentation cockpit with a maximalist black/red/white Phantom UI, styled after stylized JRPG menu design: angular clip-path panels and buttons in place of rectangles, poster display type (Anton/Oswald) over calm body prose, diagonal-wipe view transitions, a Three.js shard-particle backdrop behind the idle hero (self-hosted, gated by the existing motion setting and `prefers-reduced-motion`), and a new diamond/mask logo mark. Renamed cockpit chrome to match — Track→Target, Engine→Persona, Pit Garage→Mod Shop, MCP Grid→Network, Loadout tab→Arsenal, Race Plan→Plan of Attack, Abort→Retreat, driver messages→Phantom — without touching the underlying `permissionMode` config values (`overdrive`/`balanced`/`review`), which are unchanged. Renamed the `frontend-redline-ui` skill to `frontend-phantom-ui` to document the new design language. Refreshed all `docs/screenshots/*.png` to the new look.
- Fixed a bug where the cockpit could load and render but never respond to a single click: the Google Fonts `<link rel="stylesheet">` sat ahead of the `<script type="module">` in `<head>`, and a slow or unreachable font host blocks every deferred/module script positioned after it, per spec, until that stylesheet resolves — with no console error to point at the cause. The font now loads via an async `rel="preload"` + `onload` swap (with a `<noscript>` fallback), so the UI stays fully interactive on any network, fonts included or not.
- Redesigned the logo mark as an angular masquerade-mask silhouette (red slit eyes on a white band, over a red diagonal slash) in place of the previous abstract diamond glyph, so the mark reads as "mask" rather than an unrelated shape; used unchanged as the favicon, PWA icon, and brand lockup.
- Coherence pass over the Phantom UI: the idle hero's floating badge is now a target-lock reticle (static corner brackets plus a pulsing diamond) instead of two disconnected floating dots; the eyebrow label and headline gained a matching bracket/skew treatment; starter-prompt buttons get a directional accent bar on hover; the view-switch wipe gained a white leading edge and dark trailing edge instead of a single flat red bar; the hero's Three.js shard field now bursts radially from the badge in a red-dominant mix instead of scattering white-heavy confetti across the whole viewport; and the previously-unused `cyan`/`magenta`/`gold` accent tokens and `.skill`/`.mcp`/`.automation`/`.plugin`/`.bridge` card classes are now wired together so every capability category has one consistent color everywhere it appears (tag text and card accent border alike). Removed a dead, never-referenced `.jagged-line` CSS rule. Added visible `:focus-visible` rings across every interactive element for keyboard navigation. Fixed the chat transcript replaying its entrance animation for every message on every polling tick during a run by scoping it to `.message:last-child`. Refreshed all `docs/screenshots/*.png` to match.

## 1.0.0 — 2026-09-02

- Initial production baseline of the MaskShift maximalist coding harness.
- Added a zero-runtime-dependency Node.js 22 daemon and responsive Redline racing web cockpit.
- Added 143 native tools and 36 bundled lazy-loaded skills.
- Added model routing for Ollama, OpenAI Responses, OpenAI-compatible endpoints, Anthropic, Gemini, OpenRouter, LM Studio, and vLLM.
- Added modern stateless and legacy MCP support over stdio and Streamable HTTP, imported configuration, resources, prompts, qualified tools, and official registry installation.
- Added repository indexing, context construction, project-instruction import, persistent memory, sessions, plans, run history, SSE telemetry, and SQLite/FTS persistence.
- Added host filesystem and shell execution, persistent processes, Git checkpoints/worktrees, LSP, CDP browser automation, containers, Kubernetes, SSH, rsync, databases, runtimes, archives, web retrieval, plugins, scheduled automations, and external-agent bridges.
- Added automated integration tests, a full tool-calling smoke test, deployment assets, and visual QA artifacts.
