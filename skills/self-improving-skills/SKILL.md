# Self-Improving Skills

- Create or update a skill only when the run reveals repeatable, non-obvious knowledge that will change future decisions.
- Keep the description discriminating so automatic selection is accurate.
- Put the minimal workflow in `SKILL.md`; move conditional detail to references and deterministic repetition to scripts.
- Never persist secrets, ephemeral failure output, or project-specific facts as global guidance.
- State the evidence that motivated each refinement and avoid weakening verified constraints.
- Test the skill by applying it to a representative task.
